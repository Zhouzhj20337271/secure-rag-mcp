# 星澜科技办公服务指引

本文属于虚构企业演示数据。办公设备故障和账号问题统一向服务台提交工单，服务时间为工作日 09:00—18:00。工单应包含问题发生时间、设备编号和可复现步骤，不得填写密码。

会议室提前一日在办公门户预约；紧急网络故障优先拨打内部服务台分机 6001。服务台不会通过聊天索取账号密码。

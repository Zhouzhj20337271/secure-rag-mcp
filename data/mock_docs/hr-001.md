# 人事部门入职档案办理指引

本文属于虚构企业演示数据。人事专员应在员工入职后 3 个工作日内核对劳动合同签署状态、建立档案索引，并记录培训安排。

档案正文保存在受限档案系统中。跨部门协作只发送办理状态，不发送证件号码或合同扫描件。本演示文档不包含真实个人资料。

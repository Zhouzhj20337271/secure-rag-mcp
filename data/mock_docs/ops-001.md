# 数据库连接池 ERR_GATEWAY_502_DB 排查手册

本文属于虚构企业演示数据。ERR_GATEWAY_502_DB 表示网关等待数据库连接超时。典型表现为接口间歇返回 502，连接池等待队列持续增加；这不等同于数据库密码错误。

先检查连接池 active、idle 和 pending 指标，再检查慢事务及未释放连接。优先终止已确认的异常长事务，并回滚最近引入的连接泄漏代码。直接扩大连接池可能进一步压垮数据库，应在容量确认后执行。

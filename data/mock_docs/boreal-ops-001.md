# 北辰 ERR_GATEWAY_502_DB 专用处置

本文属于虚构企业演示数据。北辰系统中的 ERR_GATEWAY_502_DB 由演示连接代理的维护切换触发，恢复步骤为先确认维护窗口，再重新加载代理路由。

本租户演示校验标记为 BOREAL-DEMO-319。此处置与星澜租户的连接池排查不同，不得跨租户混用；同名错误码是用于检验隔离和引用准确性的干扰样本。
